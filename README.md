Alcohol Detection System

Overview
The Alcohol Detection System is a web-based application that detects whether a person has consumed alcohol using AI/ML techniques. The system provides quick prediction results through a simple user interface.

 Features
- Alcohol detection prediction
- User-friendly web interface
- Database integration
- Fast prediction results
- Flask-based backend

 Technologies Used
- Python
- Flask
- HTML
- SQLite
- Machine Learning
- CSS
- JavaScript


Installation
bash
git clone https://github.com/yourusername/Alcohol-detection-system.git
cd Alcohol-detection-system
pip install -r requirements.txt
python app.py
